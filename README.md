# Credit Card Delinquency Prediction

An end-to-end data science project focused on preprocessing financial data, performing exploratory data analysis (EDA), and building a predictive machine learning model to identify high-risk credit card accounts and mitigate default risks.

---

## Project Overview

Credit card delinquency prediction is critical for financial institutions to proactively manage risk, reduce default rates, and optimize lending strategies. This project utilizes Python and machine learning classification techniques to analyze historical financial behaviors and predict whether an account is likely to become delinquent.

---

## Tech Stack & Libraries

* **Programming Language:** Python
* **Data Manipulation & Analysis:** Pandas, NumPy
* **Machine Learning & Evaluation:** Scikit-learn (Logistic Regression, Confusion Matrix, Classification Metrics)

---

## Key Features & Methodology

* **Data Preprocessing & Cleaning:** Handled missing values, formatted financial features, and standardized variables to ensure high data integrity for modeling.
* **Exploratory Data Analysis (EDA):** Applied statistical analysis and data visualization to uncover key financial indicators and delinquency drivers.
* **Predictive Modeling:** Developed and trained a **Logistic Regression** classifier to predict account delinquency status.
* **Model Evaluation:** Evaluated model performance achieving **85% accuracy**, utilizing robust classification metrics including:
  * Precision[cite: 1]
  * Recall[cite: 1]
  * F1-Score[cite: 1]
  * Confusion Matrix[cite: 1]
