# Credit Card Delinquency Prediction

An end-to-end data science and machine learning project focused on analyzing credit card customer data, identifying financial risk patterns, and predicting potential credit card delinquency using classification techniques. The project leverages Python, exploratory data analysis, and Logistic Regression to help identify high-risk accounts and support proactive credit risk management.

---

## Project Overview

Credit card delinquency is a significant challenge for financial institutions, as delayed payments and defaults can lead to financial losses and increased credit risk.

**Credit Card Delinquency Prediction** aims to address this challenge by applying data science and machine learning techniques to historical credit card customer data. The project involves data preprocessing, exploratory data analysis (EDA), statistical analysis, and predictive modeling to identify customers who are likely to become delinquent.

Using Logistic Regression, the project analyzes relevant financial attributes and customer payment patterns to classify accounts based on their delinquency risk.

The primary objective is to support better financial risk assessment, enable early identification of potentially delinquent accounts, and assist financial institutions in making informed lending decisions.

1. **Data Collection:** Load historical credit card customer data for analysis.
2. **Data Preprocessing:** Handle missing values, clean data, and prepare relevant features.
3. **Exploratory Data Analysis:** Examine distributions, correlations, and customer payment patterns.
4. **Feature Preparation:** Select and prepare relevant features for predictive modeling.

6. **Model Evaluation:** Evaluate model performance using accuracy, precision, recall, F1-score, and confusion matrix.
7. **Result Analysis:** Interpret model predictions and identify potential delinquency risk patterns.

---

## Model Evaluation Metrics

The Logistic Regression model is evaluated using the following performance metrics:

- **Accuracy:** Measures the overall proportion of correct predictions.
- **Precision:** Measures how many accounts predicted as delinquent are actually delinquent.
- **Recall:** Measures how effectively the model identifies actual delinquent accounts.
- **F1-Score:** Provides a balance between precision and recall.
- **Confusion Matrix:** Provides a breakdown of correct and incorrect classification predictions.

These metrics help assess the model's effectiveness in identifying potentially high-risk credit card accounts.
